📡 **Decodium 4 FT2 — v1.0.385**
🧩 DX Cluster agganciabile nel layout (4ª colonna)

🛠 **Cosa cambia**
• Il **DX Cluster** ora si può **integrare nel layout** come gli altri pannelli, in una **4ª colonna dedicata** accanto a Full Spectrum / Signal RX / Live Map — **senza sostituire nessuno**.

## 🇬🇧 English

📡 **Decodium 4 FT2 — v1.0.385**
🧩 DX Cluster dockable in the layout (4th column)

🛠 **What changed**
• The **DX Cluster** can now be **docked into the layout** like the other panels, in a **dedicated 4th column** next to Full Spectrum / Signal RX / Live Map — **without replacing any of them**.
• Open the Cluster: the 4th column shows **"⤓ Dock DX Cluster here"**. One click and it embeds inline; the **⤢** button sends it back to a floating window.
• The column is **resizable** (width is saved) and **repositionable** with the ⠿ handle.
• Default stays as before (floating window, 3 columns): the 4th column appears only when you dock the Cluster.
