# Decodium 4 FT2 1.0.488

## Italiano

Punti principali (`1.0.487 -> 1.0.488`):

- **Traduzioni complete in 13 lingue** per le funzioni introdotte nella 1.0.487 (aggiornamento
  automatico e piattaforma di assistenza): l'avviso di aggiornamento, le sue note e i pulsanti,

  community appaiono ora nella lingua dell'applicazione. Lingue: inglese, italiano, catalano, danese,
  tedesco, spagnolo, francese, ungherese, giapponese, lettone, russo, cinese semplificato e tradizionale.
- Nessun'altra modifica rispetto alla 1.0.487.
