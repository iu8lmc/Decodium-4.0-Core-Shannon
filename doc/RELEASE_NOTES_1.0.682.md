# Decodium 1.0.682 — CW remoto in modo CW

- When remote radio control is enabled while the application is in CW, Decodium
  now commands the remote radio to stay in CW instead of switching it to DIGU.
- Digital modes continue to select DIGU; SSB continues to use its configured
  radio mode.
- Includes the CW typing and FT-991/A CAT corrections from 1.0.681.

Windows x64 installer. Verify RF transmission with the target radio and remote
gateway before operating on air.
