# Decodium 1.0.675

## English

This release aligns with the upstream 1.0.674 fixes and improves the CW and radio controls introduced in 1.0.673.

### Highlights

- CW live typing starts transmitting immediately, without waiting for a typing pause.
- Added CAT radio Power On alongside Power Off, keeping the CAT session available for power recovery.
- Added dashboard shortcuts for ATU tune, Power On, and Power Off below the audio levels and monitor controls.
- Retained the 1.0.674 Linux CW linkage and FT2/Multi-Answer sequencing fixes.

## Italiano

Questa versione integra le correzioni upstream della 1.0.674 e migliora le funzioni CW e i controlli radio introdotti nella 1.0.673.

### Novità principali

- La digitazione CW avvia la trasmissione immediatamente, senza attendere una pausa nella scrittura.
- Aggiunto Power On CAT accanto a Power Off; la connessione CAT resta disponibile per riaccendere la radio.
- Aggiunti nella dashboard i comandi rapidi ATU Tune, Power On e Power Off, sotto i livelli audio e i controlli monitor.
- Mantenute le correzioni 1.0.674 per il collegamento CW su Linux e il sequenziamento FT2/Multi-Answer.

Il pacchetto Windows viene compilato e allegato alla release GitHub tramite il workflow dedicato.
