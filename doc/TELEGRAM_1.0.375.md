## 🇬🇧 English

📡 **Decodium 4 FT2 — v1.0.375**
🔄 Upstream alignment release — security, robustness and stability

🔒 **Security & robustness**
• Remote web dashboard protected by an access token
• ADIF and working-frequency imports now bounded against malformed/oversized files
• Hardened DX Cluster and TCI parser (no unbounded memory, invalid values dropped)

📻 **Safer radio / TX sequencing**
• Wait & Pounce no longer transmits from a decode alone: it only starts if TX/CQ is already armed
• R-report/RR73 messages can't replace the active QSO unless they match the current partner
• More reliable FT2 async: retry cap, total timeout, cancel on mode/state/hold change
• Check SWR no longer blocks Tune (still enforced for TX/AutoCQ)

🛠 **Stability & UI**
• Crash fixes on Linux/PipeWire and macOS/CoreAudio
• Clearer Setup, Astro/Macro pop-outs draggable again, footer fixed, tooltips revised
