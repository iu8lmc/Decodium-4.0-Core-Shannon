## 🇬🇧 English

📡 **Decodium 4 — v1.0.409**
🔧 FT8/FT4 decode again + new armed DX-watch + smoother UI

🛠 **What changed**
• **Fixed "no decode" in FT8/FT4** — on some PCs the Full Spectrum window stayed **empty, zero rows**: a filter added in a recent version mistakenly dropped the decode pass that fills the list. Rows now appear correctly again. The same fix was extended to **FT2**. Thanks to the testers who reported it and tried it on the air. 🙏
• **New — armed DX-watch (Call window)** — you can now **"arm" a callsign** and leave Decodium **listening without transmitting**: it doesn't occupy the channel and calls no one. It **starts calling on its own, only when that DX shows up** on the band (with optional re-arm). Off by default.
• **Smoother UI under heavy decoding** — even with many decode threads set manually, Decodium now **always reserves a few cores for the graphics** → fewer window freezes during the heaviest decode passes.
