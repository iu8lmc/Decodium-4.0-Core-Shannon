# Decodium 4 v1.0.622

## English (UK)

This release consolidates the changes delivered from v1.0.619 through v1.0.622.

- Added persistent Wanted Callsigns alerts with exact and `*` wildcard matching.
- Matching decodes are highlighted and can trigger a de-duplicated alert sound.
- Added EasyLog-compatible lowercase ADIF `BAND` output (`20m`, `40m`, etc.) for raw UDP logging, enabled by default and configurable in Settings.
- Retained the SuperFox controls, CAT/PTT safeguards, UI corrections and logging improvements from the preceding releases.
- GitHub Actions produces the Windows x64 installer, macOS Apple Silicon and Intel DMGs, and Linux x86_64/aarch64 AppImages.

## Italiano

Questa release consolida le modifiche dalla v1.0.619 alla v1.0.622.

- Aggiunti gli avvisi persistenti per i callsign desiderati, con matching esatto e wildcard `*`.
- I decodes corrispondenti vengono evidenziati e possono generare un avviso sonoro senza duplicazioni.
- Aggiunto l'invio ADIF UDP compatibile con EasyLog del campo `BAND` in minuscolo (`20m`, `40m`, ecc.), attivo di default e configurabile nelle Impostazioni.
- Mantenuti i controlli SuperFox, le protezioni CAT/PTT, le correzioni dell'interfaccia e i miglioramenti del logging delle release precedenti.
- GitHub Actions genera installer Windows x64, DMG macOS Apple Silicon e Intel e AppImage Linux x86_64/aarch64.

The GitHub source archives contain the complete tagged codebase.
