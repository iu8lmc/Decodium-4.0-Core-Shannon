## 🇮🇹 Italiano

📡 **Decodium 4 FT2 — v1.0.388**
⚡ Priorità processo + filtro CQ rapido + rifiniture

🛠 **Cosa cambia**
• **Priorità processo (Windows)** — in *Settings → UI — PERFORMANCE* scegli Normale / Sopra il normale / **Alta (consigliata)** / Tempo reale ⚠️. Se noti scatti su audio/decode prova **Alta**: più fluidità, rischio basso. (Tempo reale dà il massimo ma può rendere il PC poco responsivo e richiede avvio come amministratore.)
• **Filtro CQ rapido** — nuovo pulsante **CQ▾** nella toolbar TX, accanto a Tune: un click cicla OFF → CQ → CQ·73 → CQ·RR73 → CQ·RRR. Spostabile come gli altri.
• **Bypass filtri** — quando attivo ora è **rosso e lampeggia**: impossibile non accorgersene.
• **DX Cluster** — il pulsante **"⤢ Stacca"** è ora leggibile e, quando stacchi il Cluster, la sua colonna **sparisce pulita** (niente spazio vuoto né maniglia residua).

## 🇬🇧 English

📡 **Decodium 4 FT2 — v1.0.388**
⚡ Process priority + quick CQ filter + polish

🛠 **What changed**
• **Process priority (Windows)** — in *Settings → UI — PERFORMANCE* pick Normal / Above normal / **High (recommended)** / Realtime ⚠️. If you see audio/decode stutter, try **High**: smoother, low risk. (Realtime gives the most but can make the PC unresponsive and needs running as administrator.)
• **Quick CQ filter** — new **CQ▾** button in the TX toolbar, next to Tune: one click cycles OFF → CQ → CQ·73 → CQ·RR73 → CQ·RRR. Movable like the others.
• **Bypass filters** — when active it's now **red and blinking**: impossible to miss.
• **DX Cluster** — the **"⤢ Detach"** button is now readable, and when you detach the Cluster its column **disappears cleanly** (no empty space or leftover handle).
