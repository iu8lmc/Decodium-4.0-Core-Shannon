Se il pulsante non funziona

Prima cosa: ricarica questa pagina con Ctrl+F5. Il browser tiene in cache la versione precedente, e quella veniva rifiutata da GitHub perche' priva di redirect_url.

Se il rifiuto persiste, registra l'app a mano da github.com/settings/apps/new: i valori esatti da inserire sono nel README.md accanto a questo file.

Premendo il pulsante si apre GitHub con il modulo già compilato. Nulla viene creato finché non premi tu «Create GitHub App» su GitHub. Dopo la creazione GitHub ti riporta all'elenco delle tue app: apri decodium-agent, genera una private key, annota l'App ID e installala sul repository desiderato.
