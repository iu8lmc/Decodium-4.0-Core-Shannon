## 🇬🇧 English

📡 **Decodium 4 FT2 — v1.0.387**
🚀 New FT8 decoder (upstream) + DX Cluster in the layout

🛠 **What changed**
• **Improved FT8 decoder** — merged Salvatore's big upstream update (new decode stage + better metrics): more decodes, especially on weak signals.
• **DX Cluster dockable in the layout** — from the Cluster window use **"Insert into layout: ◧ next to Full Spectrum / ◧ next to Signal RX"**: the Cluster becomes a workspace column. The **⤢** button sends it back to a floating window and the column disappears. Resizable and repositionable (⠿ handle).
