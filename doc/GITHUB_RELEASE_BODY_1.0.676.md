# Decodium 1.0.676

## English (British)

This release consolidates the fixes and features delivered from 1.0.674 through 1.0.676.

### Highlights

- Fixed the Linux legacy `wsjtx` build by exposing the CW include path and linking the CW module required by `DecodiumBridge`.
- Fixed CW live text transmission: typed characters are queued and sent sequentially after the active transmission completes, preventing overlapping letters, lost keystrokes and malformed keying.
- Retained the CW typing and radio power controls introduced in 1.0.675, together with Decolink remote-radio support, FT2/Multi-Answer echo handling, SSTV and multi-stream improvements.
- Retained the CMake and compiler/linker warning cleanup, including static-library deduplication and legacy C conversion fixes.
- Release packaging is generated by GitHub Actions for Windows x64, macOS Intel, macOS Apple Silicon, Linux x86_64 and Linux aarch64.

## Italiano

Questa release raccoglie le correzioni e le funzionalità introdotte dalla 1.0.674 alla 1.0.676.

### Novità principali

- Corretto il build Linux del target legacy `wsjtx`, rendendo disponibile il percorso degli header CW e collegando il modulo CW richiesto da `DecodiumBridge`.
- Corretta la trasmissione del testo CW durante la digitazione: i caratteri vengono accodati e inviati in sequenza al termine della trasmissione attiva, evitando sovrapposizioni, caratteri persi e manipolazione errata.
- Conservati i controlli di digitazione CW e di potenza radio introdotti nella 1.0.675, insieme al supporto radio remota Decolink e ai miglioramenti FT2/Multi-Answer, SSTV e multi-stream.
- Conservata la pulizia CMake e dei warning di compilazione/linking, inclusa la deduplicazione delle librerie statiche e la correzione delle conversioni nel C legacy.
- I pacchetti di release vengono generati dai GitHub Actions per Windows x64, macOS Intel, macOS Apple Silicon, Linux x86_64 e Linux aarch64.
