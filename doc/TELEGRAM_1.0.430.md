📡 **Decodium 4 — v1.0.430**

🛠 **What changed**
• **Reboot after install: now your choice** — in 1.0.428 the reboot was forced. Now, when the install finishes, a prompt **strongly recommends** restarting (audio, CAT and caches start clean), with the **"Yes" button preselected**. Accept → 15 s countdown; decline → **no reboot**.

• **"Caller retries" finally respected** — the maximum number of TX repeats set in FT2 is now a **hard limit** that **always** applies, even with the TX Watchdog on. TX logic only: **the decoder is unchanged**.
