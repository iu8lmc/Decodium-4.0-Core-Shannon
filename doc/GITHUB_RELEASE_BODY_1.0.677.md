# Decodium 1.0.677

## English

This release restores CW transmission while keeping the radio in CW mode.

- On supported Hamlib radios, CW text uses the radio's built-in CAT keyer, including the Stop command. A serial keyer or WinKeyer remains available as a fallback.
- Remote CW continues to use native DecoLink keying when supported, avoiding the audio frequency offset.
- Improves live CW typing and character handling when editing text.

## Italiano

Questa versione ripristina la trasmissione CW mantenendo la radio in modo CW.

- Sulle radio Hamlib compatibili, il testo CW usa il manipolatore CAT interno, incluso il comando Stop. Restano disponibili come alternativa il manipolatore seriale e WinKeyer.
- Il CW remoto continua a usare la manipolazione nativa DecoLink quando supportata, evitando lo spostamento di frequenza dell’audio.
- Migliora la digitazione CW in tempo reale e la gestione dei caratteri quando si modifica il testo.
