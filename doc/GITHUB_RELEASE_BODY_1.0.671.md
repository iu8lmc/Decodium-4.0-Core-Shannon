# Decodium 4 v1.0.671 — CW VFO and signal centering

## English

- Tune the radio from the CW window: editable MHz frequency, mouse wheel and minus/plus controls with 1, 10, 50, 100 and 1000 Hz steps.
- **Center CW** adjusts the radio frequency using the measured receive tone. Set Decoder tone to **Auto**, match Center tone to the radio CW pitch, and select the correct CW-U/CW-L receive sideband (including CW-R).
- Uses local CAT or the selected remote radio while preserving its operating mode. Tuning is blocked during transmission; centering rejects missing, locked or stale decoder measurements.
- Improved compact layout, with the VFO and centering button to the right of the decoder switch.
- Includes the remote RX listening, CW keyer/macros and antenna-control features from 1.0.670.

Windows x64 installer and portable ZIP include runtime libraries and auxiliary programs.
Software build, CW tests and offscreen UI checks completed. Local/remote hardware verification remains necessary.

## Italiano

- VFO nella finestra CW: frequenza modificabile in MHz, rotellina, pulsanti meno/più e passi di 1, 10, 50, 100 e 1000 Hz.
- **Centra CW** regola la frequenza della radio sul tono ricevuto. Impostare Tono del decodificatore su **Auto**, Tono centro uguale al pitch CW della radio e selezionare il lato CW-U/CW-L corretto, anche quando si usa CW-R.
- Sintonia tramite CAT locale o radio remota selezionata, senza modificare il modo operativo. Blocco durante TX e rifiuto di misure assenti, bloccate o precedenti alla sintonia.
- Layout compatto aggiornato; VFO e pulsante di centratura a destra dell'interruttore del decodificatore.
- Conservate le funzioni della 670: ascolto RX remoto, modulo CW, macro e controllo antenna.

Installer e ZIP portabile Windows x64 completi di librerie e programmi ausiliari.
Verificati compilazione, test CW e interfaccia fuori schermo. Da verificare sulla radio locale/remota reale.
