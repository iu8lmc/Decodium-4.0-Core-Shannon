## 🇬🇧 English

📡 **Decodium 4 FT2 — v1.0.395**
🎛 Remote CW + FT2 anti-ghost filter

🛠 **What changed**
• **Remote control — send CW** — new command that sends text in CW through the rig's keyer (Hamlib `send_morse`), with adjustable speed (5–60 WPM). The rig must be in CW mode. Handy for operating the station from a phone/app.
• **Remote control — no token on localhost** — an app on the same PC (e.g. a WebSDR bridge) can command Decodium without juggling a token. Over the network (LAN) the token stays mandatory: network security is unchanged.
• **FT2 — stricter anti-ghost filter** — a very weak, never-before-heard caller must now confirm with a second decode before triggering AutoCQ: the decoder's "ghosts" (random callsigns appearing for a single slot) no longer make you chase non-existent stations. A real weak caller only costs one extra period.
